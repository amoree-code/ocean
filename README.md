# Ocean

One repository for the whole Ocean workspace. The root mirrors `~/ocean/`: the engine in
[`kernel/`](kernel/) is public and complete, and every workspace directory is shown as an
empty folder (`.gitkeep`). Its files hold private data and never leave the machine.

The root `.gitignore` is a whitelist: anything not listed there is ignored, so a private file
cannot be committed by accident.

```text
~/ocean/
├── 00-inbox/          intake waiting for triage
├── 01-daily/          daily summaries
├── 02-personal/       durable personal facts; MEMORY.md is the index
├── 03-professional/   work documents and applications
├── 04-projects/       projects, grouped by category
├── 05-knowledge/      reusable lessons and decisions; KNOWLEDGE.md is the index
├── 06-templates/      templates for tasks, decisions and sessions
├── charter/           rules and policies every AI client loads
├── bridge/            machine-local runtime state: config, profiles, sessions, skills
├── .index/            generated search index, rebuildable
└── kernel/            the public engine: packages/, docs/, scripts/
```

## Projects

Each project lives in the folder of its category. The folder is the category.

```text
04-projects/
├── registry.md        project index, generated by `ocean project index --write`
├── backlog.md         follow-ups too small to be a task
├── company/
├── personal/
├── freelance/
├── former-company/
├── vendor/
└── uncategorized/     where a new project lands until it is moved
    └── <project>/
        ├── project.json   id, paths, tags
        ├── MEMORY.md      index of the project's memory
        ├── memory/        lessons
        ├── docs/          reference material
        └── tasks/         one folder per task
```

```bash
ocean project move <project> <category> --write   # file a project under a category
ocean project list --category company             # list one category
```

To work on the engine, see [`kernel/README.md`](kernel/README.md).
