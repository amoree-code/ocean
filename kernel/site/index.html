Ocean

One workspace for every AI agent you use. Ocean gives Claude Code, Codex, Gemini CLI, Qwen, Cursor, OpenCode and other AI clients the same projects, tasks, memory and knowledge, on your machine, without a hosted service.

View on GitHub npm package

Why Ocean

Every AI client keeps its own memory, its own history and its own idea of what you were doing. Switch clients and the context is gone. Ocean moves that state out of the clients and into one place you own: projects, tasks, decisions and sessions live as plain files on your disk. A task started in Claude Code can be continued in Codex, reviewed in Gemini and closed from the terminal, with nothing explained twice.

Install

npm install --global @amoree-code/ocean
ocean setup
ocean clients apply --yes   # connect Ocean's MCP server to your AI clients
ocean doctor

Requires Node.js 22.16 or newer. macOS and Linux; Windows runs the engine and its tests.

Principles

  • Local-first. Your records are files on your machine. No account, no server, no sync service.
  • Provider-neutral. Claude, Codex, Gemini and others are entry points; the workspace outlives any of them.
  • Storage is not context. Agents get a small, bounded packet of what the work needs, not the whole workspace.
  • MCP-native. One MCP server exposes memory, tasks and sessions to every connected client.
  • Verified, not claimed. Completion is an independent check passing, not an agent saying "done".
  • Explicit authority. Reads are free; writes, installs and promotions need an explicit flag.
