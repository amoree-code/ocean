# Catch up

Reconstruct only the context needed to continue safely.

1. Identify the active project and branch.
2. Read the authoritative task or session record, then inspect the current worktree.
3. Separate verified completed work from assumptions and stale history.
4. Report: project, last objective, proven work, remaining work, blockers, and one next action.

Read the smallest set of files that proves the answer. Do not modify files while catching up.
