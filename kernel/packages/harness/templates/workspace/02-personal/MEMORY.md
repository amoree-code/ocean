# Memory index

The router for personal facts. Start here, then open only the one record a task needs; the
records below are canonical, this list only points at them.

**Memory holds what is true about the owner and their world**, for years. When unsure, ask:
does it stay true even if they stop coding? Yes → a memory record. No → `05-knowledge/`.

## Retrieval rules

- Every fact lives in one record; anything else that needs it links there.
- New information that disagrees with a record goes to `CONFLICTS.md` until resolved.
- Inferred or imported facts are proposed as candidates (`00-inbox/candidates/`) for review.
